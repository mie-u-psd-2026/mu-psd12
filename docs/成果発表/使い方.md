# 成果発表資料

「何のために作ったか」「どう役立つか」を中心にした、全6枚・約6分の発表資料です。技術構成やテスト件数の説明は外し、学園祭の企画を例に説明しています。

- **スライド.pptx**：PowerPointで編集・発表できる版。各スライドの「ノート」に読み上げ原稿と時間の目安を入れています。画像以外の文字は編集できます。
- **スライド.pdf**：PowerPointから書き出した全6枚のPDF。全画面表示で発表できます。
- **スライド.html**：ブラウザで開く版。「発表表示」で1枚表示になり、左右キー・PageUp/PageDown・スペースで送れます。Escで一覧に戻ります。HTMLとassetsフォルダーを一緒に置いてください。
- **発表原稿.md**：約6分の読み上げ原稿。時間配分、操作メモ、参照元、想定質問を記載しています。本文は約1,955文字です。読み上げと間を合わせた時間の目安なので、リハーサルで調整してください。
- **assets/操作例.png**：4枚目に使ったアプリ画面。アイデアとAIの応答は説明用の固定データです。

## 構成

1. つくった目的
2. 企画を考えるときの困りごと
3. 解決したいこと
4. AIの提案でアイデアを広げる使い方
5. AIの案を自分で選べる仕組み
6. 考えを文章にまとめ、保存して活用すること

参考資料のTAPS法を構成に取り入れています。スライドには英語の構成名を出さず、聞き手に伝える内容を日本語で示しています。標準の6分構成は画像による説明で完結し、ライブデモは不要です。

## 編集するとき

PowerPointで文字や画像を編集できます。PDFを更新する場合はPowerPointから書き出してください。HTML版は別ファイルなので、PowerPoint上での修正は自動反映されません。

元の参考PDF、仕様書、WBS、アプリ、既存のテスト資料は変更していません。
