# 手動シナリオテスト結果

対象: [test-spec.md](../../test-spec.md) 4章（AI関連シナリオ）。実行者・実行日はチェック時に追記する。

## 4.1 シナリオ1: AIによるシート編集

- [ ] 1. AIショートカットホイールから「深掘り」を選択 → AI提案パネルが表示され対象がハイライトされる
- [ ] 2. 提案を却下 → シートに変更が反映されない
- [ ] 3. 再度AI機能を実行し提案を承認 → シートに変更が反映されUndo履歴が1件追加される
- [ ] 4. Undoアイコンをクリック → AI承認による変更が取り消される

## 4.2 シナリオ2: ひとりごとメモ・AIノート作成

- [ ] 1. ひとりごと入力欄にアイデアを入力し送信 → AIがノード/ノート追加を提案するパネルが表示される
- [ ] 2. 提案を承認 → 新しいノードまたはノートがシートに追加される
- [ ] 3. AIショートカットホイールから「ノートに要約」を選択、対象をシート全体にする → シート全体を要約したノート案が提案される
- [ ] 4. 提案を承認 → ノートが成果物として追加される

## 4.3 シナリオ3: AI異常系

- [ ] 1. 未保存の状態でAI機能を実行 → 呼び出し直前に自動保存され、保存失敗時はAI要求が中止される
- [ ] 2. AI提案中に他の編集や保存を試みる → 操作がロックされ実行できない
